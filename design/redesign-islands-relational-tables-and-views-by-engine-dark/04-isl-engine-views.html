One shell for every engineSame tab strip, same inspector, same status bar. The driver declares which tabs exist; the UI never checks a driver id.
The source is always namedEach statistic says where it came from and how old it is: catalog, planner statistics, metadata or a sample.
Nothing heavy runs on openMetadata and planner statistics are cheap and load with the view. Anything that reads table data is a button, audited, with its limit inside the SQL.
Files keep direct readersDuckDB queries files with SQL; MCP read-only refuses file-reading functions.
