Export wizard: states

Three states the Format and Run steps can reach. The encoding error appears only after the run starts, because the encoder meets the character while writing. The failing table is reported in the dialog and in a toast.

Differs from the app todayThe code writes these lines into one muted caption joined with “; ”. The design lists one row per table with a status icon and the failed row on a danger wash. The wording is the app's. A run with a failed table writes no manifest.json, so that folder cannot be imported.
NoteThe encoder meets the character while writing, so Continue is never blocked: pick UTF-8 or UTF-16LE and export again. Files written before the failure stay in the folder.
