Wizards: the Confirm step

Step 3 of both wizards. Export confirms its plan before writing files; import confirms only a plan that drops or empties a table, because nothing can be recovered afterwards.

1 · Export: review the plan

NoteThe export plan is a summary line and the chunk size. Nothing is changed in the database, so there is no destructive wording; Start Export is the only forward action and Back returns to Format. The folder shown is the one chosen on the Format step.

2 · Import: confirm a destructive plan (Recreate or Truncate)

4Run
This will drop-and-recreate or truncate the following table(s) before loading data: customers, orders
This cannot be undone. Confirm to proceed.
NoteImport reaches this step only when a table is set to Recreate (drop + create) or Truncate (empty + insert); a plan with no destructive mapping goes straight to Run. The dialog lists the tables that will be dropped or emptied. “Yes, proceed” is the only action that confirms; Back returns to Configure and clears the confirmation, so the next run must be confirmed again; Cancel closes the wizard without touching the target.
KeyboardTab moves between the buttons. Enter activates the focused button. Esc closes the wizard.
