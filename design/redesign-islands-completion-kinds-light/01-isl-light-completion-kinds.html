Completion menu: what each suggestion is (#1013)

The five approved points: kind word per SQL suggestion (cte included), names in their syntax color across editors with a plain fallback, width counted from the kind word and following the interface font size. Matched letters keep today's style.

1 · SQL: kind word and syntax color per suggestion

Each row names what it is, right-aligned and translated, and draws its name in the color the token gets in the editor: tables and views in the type color, schemas in the namespace color, columns in the field color, aliases italic, keywords bold. The selected row keeps the accent foreground. The menu widens to fit a long table name next to its word.

2 · A CTE is labeled cte

The query's CTE names come from the cursor analysis, so a CTE no longer reads as a table next to a table and a view with the same prefix.

1WITH active_users AS (...) SELECT * FROM act
active_userscte

3 · Other editors: color only, no kind word

MongoDB, Redis and Lua editors color METHOD, FUNCTION, CLASS and OPERATOR suggestions like the same token in their editor. VALUE and any kind without a mapping keep today's plain style (first_name). Only SQL shows the kind word.

$filter
first_name

The menu's width and rows follow the interface font size, also in editors that were already open when the size changed. The match highlight is unchanged in this design (out of scope, waiting on the editor's styling).
