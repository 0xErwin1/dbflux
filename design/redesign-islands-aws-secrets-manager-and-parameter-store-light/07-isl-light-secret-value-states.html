Formatted is the editable, indented view; Raw is the stored text. Invalid JSON blocks Save and names the line.

Rules

  • The view picks the format from the value: AWS stores none. One-level JSON objects open as key/value; nested JSON is indented; text that parses as KEY=value lines is highlighted as dotenv; anything else is plain text.
  • Line breaks are always kept. Long lines wrap in the details pane and scroll horizontally in the editor tab.
  • Formatting is a view. Copy value and Copy JSON always copy the stored text.
  • Saving writes a new version and moves AWSCURRENT to it. JSON edited in Formatted is written back in the layout it had: compact stays compact.
  • Hidden shows dotenv keys and masks every value; other text masks every line. Space toggles, the tab forgets the value on close.
  • Open in editor (o) and Edit value (e) open the same editor tab. Secrets managed by another service and binary secrets stay read only.
