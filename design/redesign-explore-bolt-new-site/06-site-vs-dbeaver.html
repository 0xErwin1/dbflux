A free, open-source alternative to DBeaver.

DBeaver Community is free and open source, and it is a good client. The difference is where the line between editions falls: MongoDB, Redis, DynamoDB, the visual query builder and charts are PRO features in DBeaver and part of the one free build in DBFlux.

What you gain
[SCREENSHOT: builder rail over a PostgreSQL join]
Build a query without writing SQL

Pick tables, joins, filters and aggregates in the builder rail. The SQL it generates is the dialect of the connection, and the result stays editable when it maps back to one table.

Visual query builder
[SCREENSHOT: Postgres tab beside a Redis cluster]
SQL and Redis in the same window

Keep a PostgreSQL query tab next to a Redis key browser, with cluster and sentinel topologies and a size check before a large value loads.

Key-value browsing
[SCREENSHOT: CloudWatch query and S3 preview]
Logs and objects next to the data

Run Logs Insights against CloudWatch, then open the S3 bucket the job wrote to, preview a file and edit it in place.

Moving over
01Install DBFluxLinux, macOS and Windows builds are on the download page. Nothing touches your DBeaver setup.
02Import your DBeaver connectionsPoint the connection manager at your workspace data-sources.json. Saved usernames and passwords come across when the DBeaver credentials file can be read, and any connection DBFlux cannot map is listed with the reason.
03Open a query tabCtrl N opens one on the active connection. The command palette finds every other action by name.
