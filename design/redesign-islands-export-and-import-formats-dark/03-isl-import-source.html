Import · Source step

Import wizard: pick a folder or a file

The first step now offers two sources: a folder written by Export, or one loose CSV, JSON or JSON Lines file that becomes a single-table import. Picking a file reads its columns and lands on Configure.

Or import a single CSV, JSON or JSON Lines file into one table.
NoteThe step is called “Pick Source” in the rail and uses the shared top stepper and a footer with Cancel, like the Export wizard. The buttons carry the text the app uses, “Choose Folder…” and “Choose File…”.

While a file or manifest is read, both buttons are disabled, the button being read says “Reading file…” or “Reading manifest…”, and the footer says why (states 2 and 5). A file with another extension stays here and says what to pick instead (last board).

NoteRight after the pick the wizard moves to Configure. The target table starts as the file name without its extension (customers_2026.csv gives customers_2026). Typing another name and pressing Use Table, or Enter, looks the table up again; Continue with an unapplied name applies it first. The table is not in the database, so the mapping mode is Create.
KeyboardTab moves between the buttons, fields and pickers. In the Target table field Enter does the same as Use Table. ← and → change a segment. Esc closes the wizard.
