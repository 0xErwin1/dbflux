NoteCSV offers three options. Changing the delimiter or the encoding reads the file again at once, because they decide where the header row splits. Here the table already exists, so the mode defaults to Existing (insert only) and values are decoded by the target column types. The unmatched columns are skipped unless remapped; this warning does not block Continue.

NoteJSON and JSON Lines have no options, so the rows are absent rather than disabled. Columns are the keys of the first objects, and with no manifest there are no source type names: a new table keeps text and JSON scalars, an existing table decodes by its column types.

The menu has five entries. Recreate drops the existing table and Truncate empties it, so both send the user to the Confirm step to approve it before anything is dropped or emptied.
On a connection that can't truncate tables the menu has four entries and Truncate isn't listed. Choose Recreate to replace the table instead.
Differs from the app todayThe code draws the mapping as plain text with three unstyled dropdowns and a ghost button, and has no Back or Cancel on this step. The design keeps the same controls in the shared form style and adds Cancel to the footer. Neither version lists the column pairs; they are changed one at a time with Target column, Source column and Apply Mapping.
KeyboardTab moves between the buttons, fields and pickers. In the Target table field Enter does the same as Use Table. ← and → change a segment. Esc closes the wizard.
