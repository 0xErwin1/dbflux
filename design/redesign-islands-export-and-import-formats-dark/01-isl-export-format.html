Export · Format step

Export wizard: choose a format and its options

The Format step lists every format the source can write, then only the options that format uses. CSV is shown in full; the others show the rows that differ. Defaults reproduce the files DBFlux wrote before the options existed.

✓ shown, – hidden. A format never offers a choice that has no effect.
SQL is listed only when the source driver can generate INSERT statements. Without it the picker shows six formats and says why under the picker (see the states board).
KeyboardTab and Shift+Tab move between controls. ← and → change the selected segment of a picker. Esc closes the dialog. The segmented pickers are the only way to choose a format, so every choice stays reachable without the mouse.
Differs from the app todayThe code opens this dialog at 620 px, where seven format segments with icons run wider than the control. The design opens it at 760 px so the whole picker fits. The stepper and the footer are the shared ones from the flows board.
