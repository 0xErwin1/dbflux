# 대시보드 및 감사 — 사용자 가이드

쿼리를 차트로 만들고 저장하는 방법, 대시보드를 구성하는 방법, 실시간 인스턴스 지표를
확인하는 방법, 그리고 감사 뷰어를 사용하는 방법을 설명합니다. 이 문서는 내부 문서인
[차트](CHARTS.md), [대시보드](DASHBOARDS.md), [감사](AUDIT.md)의 *사용 방법* 동반
문서입니다.

---
## 저장된 차트

### 쿼리 결과 차트 만들기

1. 표 형태 데이터를 반환하는 쿼리를 실행합니다.
2. 결과 그리드에서 오른쪽 클릭하고 **이 쿼리를 차트로**를 선택합니다.

차트 문서가 열리며, 실행한 쿼리로 채워지고 자동으로 실행됩니다. 이 옵션은 결과에
사용할 수 있는 원본 쿼리가 있고 DBFlux가 차트로 만들 수 있는 열을 자동으로 감지할
수 있을 때만 나타납니다. 지원하는 차트 타입: 꺾은선, 막대, 분산, 영역, 누적 막대,
원형. 축 감지는 각 열의 유형(시간, 숫자, 텍스트)을 사용합니다; 규칙은
[차트](CHARTS.md)를 참조하세요.

### 저장하고 다시 열기

- 차트 문서에서 **저장**을 누르고 이름을 지정합니다. 같은 차트를 다시 저장하면
  덮어씁니다(중복 없음).
- 명령 팔레트의 **차트 열기…**로 저장된 차트를 다시 엽니다 — 활성 연결의 저장된
  차트를 나열합니다. (저장된 차트가 없으면: *"현재 프로필에 저장된 차트가 없습니다"*.)
- 저장된 차트는 사이드바의 **저장된 차트** 아래에도 나타나며, 각 차트에는
  **열기 / 이름 바꾸기… / 복제 / 삭제…**가 있습니다.

차트는 연결 프로필별로 저장됩니다.

## 대시보드

대시보드는 하나의 시간 범위와 하나의 새로고침 정책을 공유하는, 이름이 붙은 12열
패널 그리드입니다.

### 만들기

1. 명령 팔레트에서 **새 대시보드…**를 실행합니다(또는 사이드바의 **대시보드**
   폴더에서 **새 대시보드…**).
2. 이름을 지정합니다. 12열 그리드와 꺼진 새로고침 상태로 열립니다.

새 대시보드는 **보기** 모드로 열립니다. 사이드바의 대시보드 폴더는 저장된
대시보드를 **열기 / 이름 바꾸기… / 복제 / 삭제…**와 함께 나열합니다.

### 편집과 보기

도구 모음의 **연필 / 눈** 버튼으로 전환합니다:

- **편집** 모드는 드래그 핸들을 표시합니다 — 패널을 드래그해 순서를 바꾸고,
  가장자리나 모서리를 드래그해 12열 그리드 안에서 크기를 조정합니다.
- **보기** 모드는 읽기 전용입니다.

편집 모드에서는 포커스된 패널에서 키보드를 사용할 수도 있습니다: 이름 바꾸기는
`F2`, 제거는 `Delete`/`Backspace`, 구성 팝오버 열기는 `Enter`입니다.

### 패널 추가

**+ 패널 추가**를 클릭합니다. 선택기는 최대 세 개의 탭을 가집니다:

| 탭 | 생성 항목 |
|-----|---------|
| **저장됨** | 하나 이상의 기존 저장된 차트로 만드는 패널. |
| **쿼리** | 이름 + 입력한 쿼리로 만드는 새 패널. |
| **지표** | 드라이버 지표로 만드는 패널(연결의 드라이버가 지표 카탈로그를 노출할 때만 표시). |

각 패널의 케밥 메뉴(편집 모드)는 **구성 / 제목 편집 / 패널 제거**를 제공합니다.
**구성** 팝오버에서는 차트 타입(꺾은선, 막대, 분산, 영역, 누적, 원형) 변경, 축
바인딩 조정, **통계** 보기가 가능합니다.

대시보드는 **구분선** 스트립도 포함할 수 있습니다 — 패널을 시각적으로 묶고 클릭하면
아래의 패널을 접는 마크다운 헤더입니다.

> **차트** 패널은 저장된 차트를 참조합니다. 그 저장된 차트를 삭제하면 패널은
> 사라지는 대신 자리 표시자("차트를 찾을 수 없음 — 저장된 차트가 삭제되었습니다")가
> 됩니다.

### 시간 범위와 새로고침

도구 모음에는 다음이 있습니다:

- **시간 범위** 드롭다운: 지난 15분, 지난 1시간, 지난 6시간, 지난 24시간, 지난
  7일, 또는 **사용자 지정**(날짜 및 시/분 선택기가 나타남). 범위는 모든 차트
  패널에 한 번에 적용됩니다.
- **새로고침** 분할 버튼: 클릭하면 모든 패널을 지금 새로 고치고, 드롭다운은 자동
  새로고침 간격(또는 끄기 / 열 때 새로고침)을 설정합니다.

> **연결 끊김은 안전하게 처리됩니다.** 패널의 연결이 닫히면 새로고침 틱은
> 건너뛰어집니다 — 타이머는 유지되며 다시 연결하면 대시보드를 다시 열 필요 없이
> 자동으로 재개됩니다.

## 인스턴스 개요, 지표, 검사기

지원하는 드라이버 — **PostgreSQL, MySQL/MariaDB, MongoDB, Redis, SQL Server** — 의
경우 연결된 프로필은 사이드바의 **인스턴스 지표** 및 **인스턴스 검사기** 폴더 위에
**인스턴스 개요** 항목을 표시합니다.

- **인스턴스 개요**는 드라이버의 기본 레이아웃에서 합성된 읽기 전용 대시보드입니다
  (연결당 하나의 탭). 편집하거나 패널을 추가할 수는 없지만, **편집 가능으로 저장**을
  눌러 레이아웃을 완전히 편집 가능한 새 대시보드로 복제할 수 있습니다.
- **인스턴스 지표**는 시계열 차트입니다(예: 연결 수, 처리량).
- **인스턴스 검사기**는 실시간 서버 상태의 표 형태 스냅샷입니다(예: Postgres
  `pg_stat_activity`, MySQL 프로세스 목록, MongoDB 현재 작업, Redis 클라이언트
  목록), 공유 간격에 따라 새로 고칩니다.

### 검사기 행 작업

일부 검사기는 행별 작업(예: **연결 종료** / **세션 종료**)을 제공합니다. 이
작업들은:

- **권한 게이트** — 실행 권한이 없는 작업은 숨겨지므로 실행하면 그냥 실패할
  버튼을 보는 일은 없습니다.
- **파괴적 작업은 확인** — 파괴적인 작업은 실행 전에 확인을 요청합니다.
- **감사 기록** — 모든 시도는 감사 이벤트를 기록하고, 실패 시 해당 감사 행으로
  연결되는 링크가 있는 토스트를 표시합니다.

## 원격 대시보드(CloudWatch)

드라이버가 지원하면(CloudWatch가 참조 구현입니다) DBFlux는 업스트림 대시보드를
**탐색**하고 **가져올** 수 있습니다.

- **탐색**: 업스트림 대시보드는 사이드바에 나타납니다. 하나를 열면 **인메모리,
  읽기 전용** 대시보드로 가져와 렌더링합니다 — 소스에는 아무것도 쓰지 않고 로컬에도
  아무것도 저장하지 않습니다. **새로고침** 작업은 목록을 다시 가져옵니다. 목록은
  세션 범위이며 재시작 후에는 유지되지 **않습니다**.
- **가져오기**: **대시보드 가져오기** 명령(팔레트 또는 사이드바)은 업스트림 정의를
  가져온 차트가 포함된 새 **로컬** 대시보드로 파싱합니다. 활성 연결의 드라이버가
  가져오기를 지원할 때만 사용할 수 있습니다 — 그렇지 않으면 *"활성 연결은 대시보드
  가져오기를 지원하지 않습니다."*가 표시됩니다.

원격 대시보드는 읽기 전용 탐색/가져오기입니다; DBFlux는 소스를 절대 수정하지
않습니다.

## 감사 뷰어

감사 뷰어는 DBFlux가 기록한 모든 것 — 쿼리, 연결, 훅, 스크립트, 구성 변경,
AI/MCP 거버넌스 결정 — 을 검토하는 단일한 장소입니다.

### 열기

- 키보드: **Ctrl+Shift+A** (macOS는 **Cmd+Shift+A**).
- 명령 팔레트: **감사 뷰어 열기**.

감사 탭은 하나입니다; 다시 열면 기존 탭에 포커스가 맞춰집니다.

### 표시되는 내용

각 행은 타임스탬프, **심각도** 칩(ERROR/WARN/INFO), **카테고리** 칩, 요약을
표시합니다. 행을 펼치면 **카테고리, 결과, 행위자, 작업, 소요 시간, 요약**을 볼 수
있습니다.

카테고리 한눈에 보기:

| 카테고리 | 포함 범위 |
|----------|--------|
| **Query** | 쿼리 실행과 스캔. |
| **Connection** | 연결 / 연결 끊기 / 다시 연결. |
| **Hook** | 연결 훅 실행. |
| **Script** | Lua / Python / Bash 스크립트 실행. |
| **Mcp** | AI 클라이언트 도구 호출. |
| **Governance** | 정책 결정. |
| **Config** | 프로필과 설정 변경. |
| **System** | 시작, 마이그레이션, 내부 로그 이벤트. |

### 필터

도구 모음은 자유 텍스트 **검색**, **시간 범위**(대시보드와 같은 프리셋에 사용자
지정 추가), **타임스탬프 모드**(Local / UTC), 그리고 **수준**(Error/Warn/Info),
**카테고리**, **결과**(Success/Failure/Cancelled)의 다중 선택 필터를 제공합니다.
**지우기**는 이들을 재설정합니다.

행의 상황에 맞는 메뉴는 **행을 CSV로 복사**, **요약 복사**, 그리고 — 이벤트에 상관
관계 ID가 있을 때 — **상관 관계로 필터**를 추가합니다.

### 오류에서 감사 행까지 추적

수행한 작업이 실패하면 DBFlux는 **감사에서 보기** 작업이 포함된 토스트를
표시합니다. 클릭하면 해당 이벤트로 필터링된 감사 뷰어가 열립니다(토스트와 감사 행이
공유하는 상관 관계 ID로 일치). 상태 표시줄의 **오류 배지**는 최근 사용자 대면
실패로 미리 필터링된 뷰어를 엽니다.

### 내보내기

**내보내기** 버튼은 현재 표시된 이벤트를 확장 스키마(구조화된 세부 사항을 포함한
모든 필드)로 `~/Downloads` 폴더의 **CSV** 또는 **JSON**(`audit_export.csv` /
`audit_export.json`)에 기록합니다. 성공 토스트는 기록된 이벤트 수와 위치를
알려줍니다.

### 보존

설정된 경우 보존 일정에 따라 오래된 이벤트를 제거할 수 있습니다([설정 →
감사](SETTINGS.md#감사) 참조). 감사 로그는 그 외의 경우 사용량에 따라 늘어나며,
다른 모든 것과 같은 `dbflux.db`에 위치합니다([데이터 및
개인정보](DATA_AND_PRIVACY.md#감사-및-개인정보)).
