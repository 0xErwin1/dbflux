# 문서 컬렉션

문서 데이터베이스의 컬렉션은 문서마다 접을 수 있는 노드 하나로 된 트리로 열립니다. **테이블**과 **JSON**은 같은 페이지를 보여 주며, 트리 / 테이블 / JSON 전환 컨트롤이나 `t` 키로 바꿀 수 있습니다. 선택한 뷰는 페이지를 넘기거나 새로 고쳐도 해당 탭에서 유지됩니다. 테이블에서는 `_id`가 먼저 오고, 나머지 필드는 페이지가 반환한 순서를 따릅니다.

- 중첩 객체는 필드 수를, 배열은 길이를 보여 줍니다. 객체 열에서 `e`를 누르면 제자리에서 열 그룹으로 펼쳐지고, 객체나 배열에서 `Enter`를 누르면 그 안으로 들어가 내용을 행으로 나열하며 경로를 표시합니다. `Backspace`는 밖으로 나갑니다.
- 바닥글은 문서 수를 셉니다. 드라이버가 일치하는 문서 수를 추정만 할 수 있으면 추정치로 표시됩니다.
- 지원하는 드라이버(MongoDB)는 `filter`, `project`, `sort`, `limit` 네 칸으로 된 쿼리 바를 제공합니다. 각 칸은 느슨한 JSON을 받으며 컬렉션 표본을 바탕으로 필드 경로를 자동 완성합니다. `Ctrl+Enter` 또는 **찾기**로 쿼리를 실행하고, 기록 버튼으로 이전 쿼리를 다시 실행합니다.
- 문서 옆의 **스키마** 뷰는 컬렉션을 표본 추출해 필드 경로마다 유형 분포, 존재율, 값 요약을 나열합니다. 표본 크기를 바꿀 수 있고, 둘 이상의 유형을 담은 필드는 표시되며, 값을 클릭하면 필터에 추가됩니다.
- 집계 파이프라인을 실행하는 드라이버(MongoDB)는 스키마 다음에 **집계** 뷰를 추가합니다. 파이프라인은 스테이지로 된 JSON 배열로 쓰며 느슨한 키를 허용합니다(`[{ $match: { status: 'paid' } }, { $group: { _id: '$region' } }]`). **실행** 또는 `Ctrl+Enter`로 실행합니다. 파싱되지 않는 파이프라인이나 `$` 연산자 하나를 지정한 문서가 아닌 스테이지는 편집기 아래에 보고되고 아무것도 실행되지 않습니다. 결과 문서는 문서 페이지와 분리된 자체 트리, 테이블, JSON 뷰에 표시되고 트리로 먼저 열리며 읽기 전용입니다. 편집, 삭제, 커밋할 수 없습니다. 한 번 실행하면 최대 1,000개 문서를 보여 주며, 결과가 잘리면 바닥글에 표시됩니다. `$out`이나 `$merge` 스테이지가 있는 파이프라인은 컬렉션에 쓰므로 실행 전에 다른 위험 쿼리와 같은 확인을 요청합니다. 기록 버튼은 같은 탭의 이전 파이프라인을 다시 불러옵니다.
- MongoDB에서는 테이블 편집이 대기 상태로 쌓입니다. 편집한 셀은 이전 값과 새 값을 보여 주고, 셀 메뉴에서 **변경 되돌리기**와 **필드 제거**를 쓸 수 있으며, **커밋**(`Ctrl+S`)은 문서마다 변경된 경로에만 `$set` / `$unset`을 씁니다. JSON 뷰는 문서 전체를 교체하고, 트리 편집은 바로 기록됩니다. 쓰기 전에 DBFlux는 문서를 다시 읽습니다. 페이지를 불러온 뒤 서버에서 문서가 바뀌었다면, 내 변경을 그 위에 적용할 수 있는지 알려 주고 실제 업데이트를 보여 주며 **문서 다시 불러오기** 또는 **내 변경 적용**을 제시하는 카드가 나타납니다.
