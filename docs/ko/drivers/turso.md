# TursoDB

HTTP를 통한 원격 Turso / libSQL 데이터베이스입니다.
## 한눈에 보기

- **분류** — 관계형
- **쿼리 언어** — SQL (SQLite 방언)
- **기본 포트** — 없음. 엔드포인트는 URL입니다
- **URI 스킴** — `libsql` (로컬 `sqld`의 경우 `turso`, `https`, `http`도 사용)

## 연결

| 필드 | 참고 |
|---|---|
| URL | `libsql://<database>-<org>.turso.io` 또는 로컬 `sqld`의 경우 `http://127.0.0.1:8080`. 자격 증명, 쿼리 문자열, 프래그먼트, 경로는 거부됩니다. |
| 인증 토큰 | OS 키링에 보관되며 bearer 토큰으로 전송됩니다. 인증 없는 로컬 서버에는 선택 사항입니다. |

## 기능

- `turso_serverless` SDK를 통한 Hrana-over-HTTP 전송으로, 동기 드라이버 계약이 유지되도록
  연결별 Tokio 런타임이 이를 구동합니다.
- 바인드 매개변수가 있는 임의의 SQL. 다중 문 스크립트는 하나의
  파이프라인 배치로 실행되며 첫 번째 실패한 문에서 중단됩니다.
- `sqlite_master`와 `table_info`, `index_list`,
  `index_info`, `foreign_key_list` PRAGMA에서 수행하는 스키마 검색: 테이블, 뷰, 열,
  인덱스, 외래 키, CHECK/UNIQUE 제약 조건.
- 공유 SQL 쿼리 빌더를 통한 타입이 지정된 `INSERT`, `UPDATE`, `DELETE`.
  영향받은 행을 다시 읽어 그리드가 서버 측 값을 표시합니다.
- 대화형 트랜잭션: 각 에디터 문서는 일반 실행 세션 연결 지점을 통해 자체 서버 스트림에서
  실행되므로, `BEGIN` … `COMMIT`이 여러 실행에 걸쳐 이어지는 동안 그리드 편집과 MCP 호출은
  격리된 스트림을 사용하며 절대 그 트랜잭션에 합류하지 않습니다.
- 선언된 타입에 SQLite 어피니티(affinity) 규칙을 적용한 열 타입. 표현식 열에 대해서는
  반환된 값을 스캔하여 대체합니다.
- SQL `LIMIT`/`OFFSET`, `ORDER BY`, `WHERE`를 통한 페이지 나누기, 정렬,
  필터링. CSV와 JSON 내보내기도 지원합니다.
- SQLite 스타일 코드 생성(rowid 의미론을 갖춘 `CREATE TABLE`,
  `ADD COLUMN`, `DROP COLUMN`, 인덱스, `REINDEX`)과 시각적 쿼리 빌더.
- 위험한 쿼리 감지는 공유 `SqlLanguageService`를 사용합니다: `WHERE` 없는
  `DELETE`와 `UPDATE`, `DROP`, `TRUNCATE`, `ALTER`는 다른 SQL 드라이버와 마찬가지로
  표시됩니다.
- 응답 본문을 노출하지 않으면서 인증 실패, 제약 조건 위반, 구문 오류,
  누락된 개체, 사용 중인 서버에 대한 오류 분류.

## 제한 사항

- 쿼리 취소가 없습니다. 요청은 서버가 응답하거나 SDK의
  전송 계층이 포기할 때까지 실행됩니다.
- SSH 터널, 내장 복제본, 로컬 파일, 동기화가 없습니다. 로컬 `sqld`
  인스턴스는 일반 HTTP로만 접근합니다.
- 에디터에서 트랜잭션 제어는 실행당 하나의 문입니다: `BEGIN`,
  `COMMIT`, `ROLLBACK`은 각각 독립적으로 실행되며, 이를 다른 문과 섞은
  스크립트는 서버에 도달하기 전에 거부됩니다.
  `SAVEPOINT`, `RELEASE`, `ROLLBACK TO`도 같은 방식으로 거부됩니다.
- 연결당 하나의 데이터베이스입니다. `ATTACH`와 데이터베이스 전환은 노출되지 않습니다.
- 쓰기 권한 프로브가 없습니다. 변경 정책은
  읽기 전용 토큰에 대해 강화되지 않으므로, 읽기 전용 토큰을 사용한 쓰기는 실행 시점에 실패합니다.
- 인스턴스 메트릭, 검사기, 대시보드 소스가 없습니다.
- Turso로의 데이터 전송은 검증되지 않았습니다. 드라이버는 대량 삽입을 광고하지만
  전송 엔진은 Turso 엔드포인트에 대해 시험된 적이 없습니다.
- 결과는 행이 반환되기 전에 SDK가 완전히 버퍼링합니다.
- `PRAGMA foreign_keys` 토글은 노출되지 않습니다. 스트림별 설정이므로
  격리된 세션에는 적용되지 않을 것입니다.
- 요청 시간 초과는 SDK 기본값이며 아직 구성할 수 없습니다.
- 라이브 테스트는 `TURSO_TEST_URL` / `TURSO_TEST_TOKEN` 뒤에 게이트되어 있으며 `--ignored`로만 실행됩니다.
