# 개인정보 처리방침

DBFlux는 로컬 우선 데스크톱 애플리케이션입니다. 사용자에 대한 정보나 사용 방식에 대한
정보를 수집, 전송, 저장하지 않습니다. 프로젝트 웹사이트는 쿠키를 설정하지 않고
서드파티 스크립트를 불러오지 않습니다. 이 문서는 그것이 실제로 무엇을 의미하는지
설명하고, 여러분에게 도달하기까지 트래픽을 보게 되는 두 인프라 제공자를 밝힙니다.
## 핵심 요약

1. 애플리케이션은 사용자가 구성한 데이터베이스 서버로만, 요청한 쿼리를 실행하는 데
   필요한 데이터만 보냅니다.
2. 텔레메트리도, 크래시 리포트도, 사용 분석도, 계정도 없습니다. 아무것도 외부로
   보고하지 않습니다.
3. 웹사이트와 문서는 정적 페이지입니다. 쿠키를 설정하지 않고, 분석 스크립트를 실행하지
   않으며, 개별 방문자에 대한 기록을 남기지 않습니다.

## 애플리케이션

| 질문 | 답변 |
|----------|--------|
| DBFlux가 사용 데이터를 어디로 보내나요? | 보내지 않습니다. 텔레메트리도 크래시 리포터도 없습니다. |
| 업데이트를 확인하나요? | 확인하지 않습니다. 업데이트는 GitHub 릴리스 페이지에서 찾을 수 있습니다. |
| 어떤 네트워크 연결을 열나요? | 구성한 연결만 엽니다: 사용하는 드라이버의 데이터베이스 서버, SSH 터널, 프록시, 클라우드 API. |
| 내 데이터는 어디에 있나요? | 사용자의 머신에, SQLite 파일 하나와 비밀을 위한 운영 체제 키링에 저장됩니다. |
| 내가 하는 일에 대한 기록을 남기나요? | 사용자의 머신에 있는 감사 로그뿐입니다. 연결, 쿼리, 훅 실행을 기록해 검토할 수 있게 하며, 기록된 컴퓨터를 떠나지 않습니다. |
| 프로젝트와 공유되는 것이 있나요? | 없습니다. 버그 리포트와 로그는 사용자가 직접 이슈에 첨부할 때만 프로젝트에 전달됩니다. |

데이터베이스, SSH 호스트, 프록시, 클라우드 제공자로의 연결은 사용자의 머신에서
지정한 서버로 직접 이어집니다. 프로젝트는 그러한 서버를 운영하지 않으며 해당
트래픽을 볼 수 없습니다.

[데이터 & 개인정보](docs/DATA_AND_PRIVACY.md) 문서는 DBFlux가 쓰는 파일, 감사 로그가
기록하는 내용, 비밀이 저장되는 방식, 애플리케이션을 백업하거나 완전히 초기화하는
방법을 설명합니다.

## 웹사이트와 문서

`dbflux.dev`와 `docs.dbflux.dev`는 이 리포지토리에서 빌드된 정적 사이트입니다. 이
사이트들은:

- 퍼스트파티든 서드파티든 쿠키를 설정하지 않고;
- 분석, 광고, 추적 스크립트를 불러오지 않으며;
- 폰트와 에셋을 같은 호스트에서 제공하므로 페이지 조회 시 다른 도메인에 접속하지
  않고;
- 프로젝트가 방문자별로 읽을 수 있는 서버 측 로그를 보관하지 않습니다.

문서 검색은 같은 호스트에서 가져온 인덱스 파일을 대상으로 브라우저 안에서
실행됩니다. 검색어는 페이지를 떠나지 않습니다.

## 인프라 제공자

두 서비스가 프로젝트와 사용자 사이에 있습니다. 어느 쪽도 개별 방문자를 식별하는 데
사용되지 않습니다.

| 제공자 | 역할 | 보는 것 |
|----------|------|--------------|
| Cloudflare | 웹사이트, 문서, `mcp.dbflux.dev`의 문서 MCP 엔드포인트를 호스팅합니다. | 모든 호스트가 그렇듯 해당 호스트로의 모든 HTTP 요청(IP 주소와 사용자 에이전트 포함)을 봅니다. Cloudflare는 프로젝트에 집계된 트래픽 수치를 노출합니다. 방문자별 기록은 노출하지 않으며, 프로젝트는 그런 기능을 어떤 것도 활성화하지 않았습니다. |
| Google Search Console | 사이트가 Google 검색 결과에 어떻게 표시되는지 보고합니다. | Google의 크롤러와 검색 결과가 이미 아는 것뿐입니다. 어떤 페이지에서도 Google 스크립트는 불러오지 않습니다. |

Cloudflare 자체의 요청 데이터 처리 방식은
[Cloudflare 개인정보 처리방침](https://www.cloudflare.com/privacypolicy/)에
설명되어 있습니다.

## 문서 MCP 엔드포인트

`mcp.dbflux.dev`는 AI 클라이언트가 문서를 검색할 수 있게 합니다. 세션은 하나의
연결이 유지되는 동안에만 존재하며 그 안에서 주고받은 메시지만 담고 있습니다. 계정도
없고, 쿼리의 영구 저장도 없으며, 세션이 끝난 뒤 방문자와 세션을 연결하는 기록도
없습니다.

## GitHub

이슈, 풀 리퀘스트, 토론, 릴리스 다운로드는 GitHub에서 이루어집니다. 거기에 올리는
모든 내용은 공개되며
[GitHub 개인정보 보호정책](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)이
적용됩니다.

## 이 방침의 변경

이 파일은 소스 코드와 함께 버전 관리됩니다. `PRIVACY.md`의 커밋 히스토리가 변경
내역입니다. 애플리케이션이나 웹사이트가 오늘 수집하지 않는 것을 새로 수집하게 만드는
변경은 해당 버전의 릴리스 노트에서 공지됩니다.
