# 仪表盘与审计 — 用户指南

介绍如何为查询结果绘图并保存、构建仪表盘、查看实时实例指标，以及使用审计查看器。本文是[图表](CHARTS.md)、[仪表盘](DASHBOARDS.md)与[审计](AUDIT.md)这几篇内部机制文档的「怎么用」配套指南。

---

## 已保存图表

### 为查询结果绘图

1. 执行一条返回表格数据的查询。
2. 在结果网格中右键点击，选择**将此查询制作成图表**。

随后会打开一个图表文档，其中已填入你的查询，并自动运行。只有当结果带有可用的原始查询、且 DBFlux 能自动检测出可用于绘图的列时，该选项才会出现。支持的图表类型：折线图、柱状图、散点图、面积图、堆叠图、饼图。坐标轴的检测依据各列的类型（时间、数值、文本）；具体规则参见[图表](CHARTS.md)。

### 保存与重新打开

- 在图表文档中按**保存**并为其命名。再次保存同一图表会覆盖原图（不会产生重复项）。
- 在命令面板中用**打开图表…** 重新打开已保存的图表——它会列出当前连接的已保存图表。（若一个都没有，会显示「当前配置文件没有已保存的图表」。）
- 已保存的图表也会出现在侧边栏的**已保存图表**下，每个图表都有**打开 / 重命名… / 复制 / 删除…** 操作。

图表按连接配置文件分别保存。

## 仪表盘

仪表盘是一个带名称的 12 列网格，由多个面板组成，这些面板共用同一个时间范围与同一套刷新策略。

### 新建仪表盘

1. 从命令面板运行**新建仪表盘…**（或在侧边栏的**仪表盘**文件夹上运行**新建仪表盘…**）。
2. 为其命名。新建的仪表盘以 12 列网格打开，且刷新处于关闭状态。

新建的仪表盘以**查看**模式打开。侧边栏的仪表盘文件夹会列出已保存的仪表盘，并提供**打开 / 重命名… / 复制 / 删除…** 操作。

### 编辑与查看

切换工具栏上的**铅笔 / 眼睛**按钮：

- **编辑**模式下会显示拖拽手柄——拖动面板可调整顺序，拖动边缘或角可在 12 列网格内调整大小。
- **查看**模式为只读。

在编辑模式下，还可以对获得焦点的面板使用键盘：`F2` 重命名、`Delete` / `Backspace` 移除、`Enter` 打开其配置浮层。

### 添加面板

点击 **+ 添加面板**。选择器最多有三个标签页：

| 标签页 | 生成方式 |
|-----|---------|
| **已保存图表** | 由一个或多个已有的已保存图表生成面板。 |
| **来自查询** | 由「名称 + 你输入的查询」生成一个新面板。 |
| **来自指标** | 由某个驱动指标生成面板（仅当该连接所属驱动提供指标目录时才显示）。 |

在编辑模式下，每个面板的 ⋮ 菜单提供**配置… / 编辑标题… / 移除面板**。**配置**浮层可用于更改图表类型（折线图、柱状图、散点图、面积图、堆叠图、饼图）、调整轴绑定、查看**统计**以及**导出 PNG**。

仪表盘还可以包含 **Divider**（分隔条）——即以 Markdown 标题形式呈现的条带，用于在视觉上对面板分组，点击后会折叠其下方的面板。

> **图表**面板引用一个已保存的图表。若删除该已保存图表，面板会变成一个占位符（「未找到图表 — 已保存的图表已被删除」），而不会消失。

### 时间范围与刷新

工具栏上有：

- 一个**时间范围**下拉框：最近 15 分钟、最近 1 小时、最近 6 小时、最近 24 小时、最近 7 天，或**自定义**（会展开日期与小时 / 分钟选择器）。该范围会同时应用于所有图表面板。
- 一个**刷新**拆分按钮：点击可立即刷新所有面板；下拉框用于设置自动刷新间隔（或关闭 / 打开时刷新）。

> **断开的连接会被妥善处理。** 当某个面板所属的连接已关闭时，其刷新节拍会被跳过——计时器保持存活，重新连接后自动恢复，无需重新打开仪表盘。

## 实例概览、指标与检查器

对于支持的驱动——**PostgreSQL、MySQL/MariaDB、MongoDB、Redis 与 SQL Server**——已连接的配置文件会在侧边栏显示一个**实例概览**条目，位于**实例指标**与**实例检查器**文件夹之上。

- **实例概览**是根据驱动的默认布局合成的只读仪表盘（每个连接一个标签页）。你无法编辑它或添加面板，但可以按**另存为可编辑**，将其布局克隆为一个全新的、完全可编辑的仪表盘。
- **实例指标**是时序图表（例如连接数、吞吐量）。
- **实例检查器**是服务器实时状态的表格快照（例如 Postgres 的 `pg_stat_activity`、MySQL 的进程列表、MongoDB 的当前操作、Redis 的客户端列表），按共享间隔刷新。

### 检查器的行操作

部分检查器提供逐行操作（例如**终止连接** / **终止会话**）。这些操作：

- **受权限控制** — 你没有权限执行的操作会被隐藏，因此你不会看到点了也必然失败的按钮。
- **破坏性操作会先确认** — 破坏性操作在运行前会弹出确认。
- **记入审计** — 每次尝试都会记录一条审计事件；失败时会弹出 toast，并附带指向对应审计行的链接。

## 远程仪表盘（CloudWatch）

当驱动支持时（CloudWatch 是参考实现），DBFlux 可以**浏览**与**导入**上游仪表盘。

- **浏览**：上游仪表盘会显示在侧边栏中。打开某个仪表盘会拉取并将其渲染为一个**内存中的只读**仪表盘——不会向数据源回写任何内容，也不会在本地保存任何内容。**刷新**操作会重新拉取列表。该列表属于会话级作用域，重启后**不会**保留。
- **导入**：**导入仪表盘**命令（命令面板或侧边栏）会将上游定义解析为一个带有已导入图表的新**本地**仪表盘。该命令仅在当前连接所属驱动支持导入时可用——否则你会看到「当前连接不支持仪表盘导入。」

远程仪表盘只支持只读浏览与导入；DBFlux 从不修改数据源。

## 审计查看器

审计查看器是查看 DBFlux 所记录全部内容的唯一入口：查询、连接、Hook、脚本、配置变更，以及 AI / MCP 治理决策。

### 打开方式

- 键盘：**Ctrl+Shift+A**（macOS 上为 **Cmd+Shift+A**）。
- 命令面板：**打开审计查看器**。

审计标签页只有一个；再次打开会聚焦到已有的那个。

### 界面内容

每行显示时间戳、**严重级别**标签（ERROR / WARN / INFO）、**类别**标签与摘要。展开某一行可看到**类别、结果、执行者、操作、时长与摘要**。

各类别一览：

| 类别 | 覆盖范围 |
|----------|--------|
| **查询** | 查询执行与扫描。 |
| **连接** | 连接 / 断开 / 重连。 |
| **Hook** | 连接 Hook 的运行。 |
| **脚本** | Lua / Python / Bash 脚本的运行。 |
| **MCP** | AI 客户端的工具调用。 |
| **治理** | 策略决策。 |
| **配置** | 配置文件与设置的变更。 |
| **系统** | 启动、迁移与内部日志事件。 |

### 筛选

工具栏提供自由文本的**搜索**、**时间范围**（与仪表盘相同的预设项，另加自定义）、**时间戳模式**（本地 / UTC），以及**级别**（错误 / 警告 / 信息）、**类别**与**结果**（成功 / 失败 / 已取消）的多选筛选器。**清除**可将它们重置。

某一行的上下文菜单还提供**将行复制为 CSV**、**复制摘要**，以及——当该事件带有关联 ID 时——**按关联筛选**。

### 从错误跳转到对应审计行

当你的某项操作失败时，DBFlux 会弹出一个带**在审计中查看**操作的 toast。点击它会打开审计查看器，并筛选出该条事件（依据是 toast 与审计行之间共享的关联 ID）。状态栏上的**错误徽标**则会打开已预先筛选为近期面向用户失败的查看器。

### 导出

**导出**按钮会把当前可见的事件以 **CSV** 或 **JSON** 写入你的 `~/Downloads` 目录（`audit_export.csv` / `audit_export.json`），采用扩展结构（包含全部字段，含结构化详情）。成功后会弹出 toast，说明写入了多少条事件以及存放位置。

### 保留

配置后，旧事件可按保留计划清理（参见[设置 → 审计](SETTINGS.md#audit)）。除此之外，审计日志会随使用不断增长；它与其他所有数据一同存放在同一个 `dbflux.db` 中（参见[数据与隐私](DATA_AND_PRIVACY.md#audit-and-privacy)）。
