# Amazon S3

AWS S3 及兼容 S3 的对象存储，包括 Cloudflare R2 与 MinIO。

## 速览

- **类别** —— 对象存储
- **查询语言** —— 对象浏览器（无查询语言）
- **URI 方案** —— `s3`

面向 DBFlux 的 AWS S3 及兼容 S3 的对象存储驱动程序，基于 [`aws-sdk-s3`](https://crates.io/crates/aws-sdk-s3) SDK 构建，由 `s3` feature 标志门控。

## 功能

- 归类为 `DatabaseCategory::ObjectStorage` 的对象存储驱动程序，可连接 AWS S3 以及兼容 S3 的端点（Cloudflare R2、MinIO）；支持通过 AWS 配置文件/SSO 的 `AuthProfileRef` 或静态访问密钥凭据认证，并支持端点覆盖与路径风格寻址。
- 存储桶浏览：一张专用的存储桶表（名称、区域、对象数、大小、版本控制、创建时间），带搜索、刷新与创建存储桶；侧边栏以扁平方式列出存储桶，只有一层深度。
- 默认按层级分页的对象导航（AWS 控制台风格，使用驱动程序返回的续传令牌），并可切换到不分页、完整展开的树形模式。
- 对象浏览器采用分栏的树/预览布局：对象行显示键、大小、存储类别与最后修改时间；目录行显示子对象数量。
- 预览矩阵：图片通过 `img()` 原生渲染；类文本对象（txt、md、json、csv、log 等）在内联可编辑的缓冲区中打开，带脏标记、Ctrl+S 回写保存（`put_object`）、放弃，以及离开时的未保存编辑确认；PDF 与其他二进制对象则回退为元数据加下载/用外部程序打开，应用内不渲染 PDF。
- 完整的对象元数据（键、大小、内容类型、最后修改时间、ETag、存储类别、加密、版本信息如可用），并用存储类别样式区分 STANDARD/STANDARD_IA/GLACIER；归档对象降级为仅元数据（不尝试获取对象内容）。
- 可配置的预览大小上限，在获取任何对象内容之前通过 HEAD 请求检查。
- CRUD：单对象删除、递归前缀/存储桶删除（需输入确认的危险模态框，批量 `DeleteObjects`，每次请求最多 1000 个键）、创建文件夹（零字节前缀标记）、创建存储桶（名称校验、区域、版本控制/阻止公共访问/对象锁、默认加密，并在端点不支持时优雅降级）、简单流式上传（`put_object`/`ByteStream`，无分片上传），以及对象重命名（先复制后删除，绑定 `r` 键，从不使用 `F2`）。
- 预签名 URL：可选 GET/PUT 方法、15 分钟/1 小时/12 小时/7 天有效期、复制 URL 动作，以及写明有效期与签名身份的警告文案。
- 每一次 CRUD/变更操作（上传、删除、递归删除、创建文件夹/存储桶、删除存储桶、回写编辑、重命名、预签名）都在对象存储的 `EventCategory` 下审计；凭据与预签名 URL 从不被记录到日志或持久化。
- 权限与未找到类错误（`AccessDenied`、`NoSuchBucket`、`NoSuchKey`）会在消息中点名受影响的存储桶/键，而不只是 AWS 的通用错误文本。
- 客户端身份：每个请求都以 `dbflux-<version>` 作为 AWS SDK 应用名，可在 CloudTrail 的 `userAgent` 字段中看到。

## 限制

- 不支持分片上传，也没有专门的传输面板 —— 无论文件大小，上传始终通过单次流式 `put_object` 调用完成。
- 没有内嵌的 PDF 查看器；PDF 及其他非图片/文本对象只提供元数据、下载与用外部程序打开。
- 不支持生命周期规则或 ACL 管理，也不支持 S3 Select。
- 重命名是先复制后删除，且没有回滚：如果复制成功后删除失败，源键与目标键都会保留，用户需手动重试删除。
- `delete_bucket` 只在存储桶为空时才会成功；删除非空存储桶会在客户端被拒绝，并给出指向递归前缀/存储桶删除流程的提示消息。
- 预览与元数据展示受 HEAD 请求门控：在尝试任何对象内容预览之前，对象的大小与存储类别总是先通过 `head_object` 获取。
- 基于 MinIO 的真实集成测试需要 Docker，通过 `cargo nextest run -p dbflux_driver_s3 --run-ignored all` 运行。
- 没有写入权限探测：`Connection::probe_write_privilege` 有意保持 trait 默认值（`WritePrivilege::Unknown`），因为可靠的检查需要 `iam:SimulatePrincipalPolicy`，而连接所用的角色通常不具备该权限。
