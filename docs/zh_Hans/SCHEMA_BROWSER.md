# 浏览 Schema

侧边栏有三个视图，从其左侧的活动栏中选择：

- **连接** — Schema 树（数据库、Schema、表 / 集合、列、索引，以及在驱动支持时的例程文件夹）。
- **脚本** — 已保存的查询文件、脚本 Hook 和其他用户文件的文件与文件夹管理。
- **仪表板** — 所有已保存的仪表板，按所属连接分组，无论该连接是否已打开。没有连接的仪表板
  列在 **无连接** 下。双击仪表板，或选中后按 `Enter`，即可打开；右键点击可打开、重命名、
  复制或删除。`+` 按钮用于新建仪表板。

使用 `q` 或 `e` 在视图之间循环切换。在活动栏中再次选择当前显示的视图会折叠侧边栏。

## 浏览树

- `j`/`k`（或 `Down`/`Up`）— 选择下一项 / 上一项。
- `h` 折叠、`l` 展开当前节点。`Space` 展开 / 折叠。
- `g` 选择第一项，`Shift+g` 选择最后一项；`Home`/`End` 作用相同。
- `Ctrl+d`/`Ctrl+u`（或 `PageDown`/`PageUp`）— 向下 / 向上翻页。
- `/` 聚焦侧边栏搜索 / 筛选框。
- `Enter` 打开选中项（例如打开表会打开一个数据网格）。
- `r` 刷新 Schema；`d` 断开当前连接。
- `m` 打开选中项的项目菜单。

## 延迟加载

Schema 采用延迟加载。连接时，DBFlux 仅获取名称等浅层元数据；展开节点时，再按需获取列、索引等详细元数据。这样可以在大型数据库中缩短初始连接时间。

## 折叠侧边栏的临时预览

侧边栏折叠时，鼠标悬停 250 毫秒后会显示临时预览；通过键盘进入（FocusSidebar、焦点循环、方向导航或命令面板）则立即显示。只有指针和焦点都离开后才会关闭；菜单、子项选择器、已跟踪的拖放目标或调整大小期间不会关闭。未显示预览时，ToggleSidebar（Ctrl+B）会改变明确选择的折叠或展开状态；预览打开时，Ctrl+B 或可见的向左折叠按钮只会关闭预览。迁移向导的来源和目标选择器共用延迟加载的层级结构，但各自保留独立的选择。

## 例程 / 存储过程

对于声明支持例程的驱动（PostgreSQL 是第一个实现），Schema 树中包含一个 **例程** 文件夹，内有函数、存储过程、聚合函数和窗口函数。打开某个例程会打开一个只读代码文档，显示其定义。该文档不可编辑，但仍可选取并复制其中的文本；执行与变更控件会被隐藏。

## Schema 关系图

驱动声明支持外键的关系型连接（例如 PostgreSQL、MySQL/MariaDB、SQLite 和 SQL Server）可以把表及其外键绘制成关系图。在侧边栏的上下文菜单中打开：

- 在已加载的数据库上选择 **查看 Schema 关系图**，会绘制该数据库中的所有表，最多 100 个。数据库中的表更多时，会显示提示“仅显示前 100 个表 — 该 Schema 还有更多表。”
- 在表上选择 **查看关系**，会绘制该表、它引用的表以及引用它的表。

关系图在单独的标签页中打开，再次打开同一关系图会切换到该标签页。加载作为后台任务（“Schema 关系图：_数据库_”）运行，可以在任务面板中取消。每个表会列出其列，并带有 `PK`、`FK` 和 `NN`（非空）标记；连线把每个外键连接到它引用的表。

| 工具栏控件 | 作用 |
|---|---|
| `+` / `-` | 放大 / 缩小，范围为 25% 到 400%。当前缩放比例显示在旁边。 |
| **重置** | 恢复到 100% 缩放和初始位置。 |
| **排列** | 丢弃手动移动过的表的位置，并重新计算布局。 |
| **适应窗口** | 调整缩放和位置，使所有表都可见。 |
| 布局下拉菜单 | **左右**（默认）把持有外键的表放在左侧，把被引用的表放在右侧。**雪花** 把一个表放在中心，其直接相邻的表围成一圈：在 **查看关系** 中是所选的表，在数据库关系图中是关联最多的表。**紧凑** 把表按名称排序后排成紧密的网格。切换布局也会重置缩放、位置和手动移动过的表。 |
| **导出** | **复制为 DBML** 或 **复制为 SQL** 把关系图中显示的表复制到剪贴板。SQL 由 `CREATE TABLE` 语句加上为外键生成的 `ALTER TABLE ... ADD CONSTRAINT` 组成。 |
| _N_ 个表 · _M_ 个关系 | 关系图中显示的表和外键数量。 |
| **类型** / **索引** | 显示列类型（默认开启）/ 在每个表下方显示索引列表（默认关闭）。 |

拖动空白处可平移视图，拖动表可移动它（会吸附到网格），滚动鼠标滚轮可围绕指针缩放。单击表可选中它。右键点击会打开包含 **放大**、**缩小**、**布局** 和 **复制为** 的上下文菜单。右键点击表也会选中该表；有表被选中时，菜单还会增加 **检查 Schema**。选择 **检查 Schema** 或双击表，会在右侧检查器栏中打开该表，其中包含 **表**、**列**、**索引** 和 **外键** 四个部分；后两个部分只在表有索引或声明了外键时出现。键盘快捷键参见[键盘快捷键](KEYBOARD.md#schema-关系图)。
