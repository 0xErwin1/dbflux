# 隐私政策

DBFlux 是一款本地优先的桌面应用程序。它不会收集、传输或存储任何与你或你的使用情况有关的信息。项目网站不设置 Cookie，也不加载任何第三方脚本。本文档说明这在实际中意味着什么，并列出在内容送达你之前会看到流量的两个基础设施提供方。

## 快速了解

1. 应用程序只向你配置的数据库服务器发送数据，且只发送执行你所请求查询所必需的内容。
2. 没有遥测，没有崩溃报告，没有使用情况分析，也没有账号。不会有任何数据回传。
3. 网站与文档都是静态页面。它们不设置 Cookie、不运行分析脚本，也不保留任何关于个别访客的记录。

## 应用程序

| 问题 | 回答 |
|----------|--------|
| DBFlux 会把使用数据发送到任何地方吗？ | 不会。没有遥测，也没有崩溃上报。 |
| 它会检查更新吗？ | 不会。更新请到 GitHub 发布页面查看。 |
| 它会打开哪些网络连接？ | 只有你配置的那些：数据库服务器、SSH 隧道、代理，以及你所使用驱动程序对应的云 API。 |
| 我的数据保存在哪里？ | 在你自己的机器上 —— 一个 SQLite 文件，加上用于保存密钥的操作系统密钥环。 |
| 它会记录我的操作吗？ | 只有审计日志，且保存在你自己的机器上。它记录连接、查询与 Hook 执行，供你事后查阅；这些记录永远不会离开写入它们的那台计算机。 |
| 会有任何内容共享给项目吗？ | 不会。只有当你在 issue 中自行附上缺陷报告与日志时，项目才会收到它们。 |

到数据库、SSH 主机、代理或云服务商的连接，都从你的机器直接连到你所指定的服务器。项目不运营其中任何一台服务器，也看不到这些流量。

[数据与隐私](docs/DATA_AND_PRIVACY.md)记录了 DBFlux 会写入哪些文件、审计日志记载哪些内容、密钥如何存储，以及如何备份或彻底重置应用程序。

## 网站与文档

`dbflux.dev` 与 `docs.dbflux.dev` 都是基于本仓库构建的静态站点。它们：

- 不设置任何 Cookie，无论是第一方还是第三方；
- 不加载分析、广告或跟踪脚本；
- 字体与静态资源都从同一主机提供，因此一次页面访问不会联系任何其他域名；
- 不保留项目可按访客读取的服务器端日志。

文档搜索在你的浏览器中运行，基于从同一主机获取的索引文件。查询内容永远不会离开该页面。

## 基础设施提供方

有两个服务位于项目与你之间。它们都不会被用于识别个别访客。

| 提供方 | 角色 | 它看到什么 |
|----------|------|--------------|
| Cloudflare | 托管网站、文档，以及位于 `mcp.dbflux.dev` 的文档 MCP 端点。 | 发往这些主机的每一个 HTTP 请求，包括 IP 地址与用户代理（User Agent）—— 这与任何主机托管方一样。Cloudflare 会向项目提供汇总的流量统计，但不会提供按访客的记录，项目也没有启用任何会这样做的功能。 |
| Google Search Console | 报告网站在 Google 搜索结果中的呈现情况。 | 只有 Google 爬虫与搜索结果本来就知道的信息。任何页面都不会加载来自 Google 的脚本。 |

Cloudflare 自身对请求数据的处理方式，见 [Cloudflare 隐私政策](https://www.cloudflare.com/privacypolicy/)。

## 文档 MCP 端点

`mcp.dbflux.dev` 让 AI 客户端可以检索文档。一次会话仅在单次连接期间存在，且只保存该连接中往来的消息。没有账号，不会对查询做持久化存储，会话结束后也不会留下把会话与访客关联起来的记录。

## GitHub

issue、拉取请求、讨论与发布版本下载都在 GitHub 上。你在那里发布的任何内容都是公开的，并受 [GitHub 隐私声明](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)约束。

## 本政策的变更

本文件随源代码一起进行版本管理。`PRIVACY.md` 的提交历史即是变更记录。如果某项变更会让应用程序或网站开始收集当前不收集的任何信息，我们会在引入该变更的版本的发布说明中予以公告。

## 联系方式

如有疑问，请在本仓库提交 issue，标题加上 `[privacy]` 前缀。
