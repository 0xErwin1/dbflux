# 键盘快捷键

DBFlux 使用分层、随上下文变化的键位映射。当前生效的层取决于哪个面板拥有焦点。以 **primary** 修饰键书写的绑定，在 macOS 上使用 `Cmd`，在其他平台上使用 `Ctrl`；以字面 `Ctrl` 书写的绑定则在所有平台上都保持 `Ctrl`（以避免与 macOS 系统快捷键冲突）。

下面的每个快捷键都可以在 **设置 → 键盘快捷键** 中修改：既可以改按键（单个组合或 `g g` 这样的序列），也可以改它生效的上下文。用空格分隔的按键（如 `y y`）需要依次按下；按下第一个键后，DBFlux 最多等待一秒接收下一个键。对话框打开时，其后的面板不会响应按键。

只有在使用键盘之后才会显示焦点：按下按键后，获得焦点的控件上会出现强调色焦点环，移动指针时保持显示，下一次点击时隐藏。获得焦点的按钮、复选框或列表行会自行处理 `Enter` 和 `Space`。

## Vim 模式（可选）

代码编辑器可以使用一组精简 Vim 命令进行模式化编辑。该功能默认关闭。在 **设置 → 常规 → 编辑器 → 在代码编辑器中使用 Vim 模式** 中开启并保存后，已打开的编辑器会立即切换。它适用于所有代码编辑器（SQL 及其他查询语言、Lua、Python、Bash），不影响其他任何输入，因此搜索框、表单和命令面板照常输入。

编辑器在打开时以及开启 Vim 模式时处于普通模式。编辑器下方的状态条显示当前模式：`普通`、`插入`、`替换`、`可视`、`可视行` 或 `可视块`。切换标签页，或把焦点移开再回来，每个标签页都保留各自的模式。状态条还会显示未完成的原始按键序列，例如 `2`、`2d3` 或 `4g`。命令完成或中断、焦点离开编辑器，或按下 `Escape` / `Tab` 时，序列会清除。这里不显示命令历史，也不会出现在工作区状态栏中。

可以在移动命令、`x` / `u` 或 `dd` / `yy` 前输入次数（例如 `3w`、`2x`、
`2u`、`3dd`、`2yy`）。也可以在重复的字母之间输入次数（如 `d2d`）；
前后次数相乘（`2d3d` 作用于六行）。操作符与移动次数也相乘：
`2d3w` 删除六次 `w` 移动覆盖的范围，`2d3j` 删除六行。
`h` / `l` 按字符选择，`j` / `k` 按完整逻辑行选择。
带次数的 `x` 最多删除到行尾，不会合并行；带次数的 `u` 撤销相应步数。
未输入次数时，`0` 移动到行首；在非零数字之后，`0` 仍属于次数
（例如 `20w`）。中断的次数不会延续到下一条命令。可视模式中，
带次数的移动会扩展编辑器选区。`gg` 和 `G` 将光标移到目标逻辑行的第一个
非空白字符；`G` 是单个大写按键。输入中断或编辑器失去焦点时，待输入的
`g` 会清除。普通模式下，`d` / `y` / `c` 配合 `gg` / `G` 从当前行到目标行按整行操作，目标限制在缓冲区内。不带次数的 `gg` 指向首行，`G` 指向末行。操作符前或移动前的次数指定从 1 开始计数的绝对行号；两处都有次数时相乘（`2d3G` 指向第 6 行）。因此 `1dG` 指向首行，与 `dG` 不同。删除只需一次撤销；只读编辑器中删除无效，但复制仍写入系统剪贴板。

仅当选中文本去除首尾空白后仍非空时，`Ctrl+Enter` 才使用选中文本；
否则使用编辑器全部内容。在可视块模式下，它与按住 Alt 拖动鼠标选择
一样，按顺序用换行符连接非空行片段；若仅选中空白，则使用整个编辑器
内容。块选区按 Unicode 标量而非视觉单元格计列：制表符、宽字符和
组合字符序列可能无法与屏幕列对齐。

普通模式下按 `/` 会打开编辑器的查找面板（与 `Ctrl+f` 相同），聚焦查询输入框并选中上次的查询。输入字面字符串；除非打开面板上的区分大小写按钮，否则匹配不区分大小写。`Enter` 把光标移到光标之后的下一个匹配，`Shift+Enter` 移到上一个匹配，到达末尾或开头后循环，面板保持打开。`Escape` 关闭面板并回到普通模式下的编辑器，光标停在最后到达的匹配上，查询保留。之后 `n` / `N` 从光标处跳到该查询的下一个 / 上一个匹配，可在前面输入次数来重复多次；面板的匹配计数随之更新。只读编辑器也支持搜索，每个标签页分别保存自己的查询。面板获得焦点时，按键会输入到面板中，而不会被当作 Vim 命令。这里是字面文本搜索，不支持正则表达式。

**本地标记。** 标记只属于当前代码文档，不在标签页或会话之间共享。只读编辑器
也可以设置标记。原生文本编辑（包括插入模式输入和输入法上屏）会让标记随文本
移动，撤销和重做时同样如此。在标记处插入文本时，标记移到插入内容之后；
删除或替换标记所在内容时，标记移到更改范围的起点，因此撤销不一定恢复其在
已删除内容中的精确位置。替换编辑器全部内容、关闭 Vim 模式或关闭文档都会
清除标记。桌面输入法（IME）行为和渲染后的界面尚未验证。

普通模式下的其他输入：

| 输入 | 普通模式下的行为 |
|------|------------------|
| 其他不支持的字母、标点、`Space` | 无操作 |
| `Tab` / `Shift+Tab` | 无操作：不缩进，焦点留在编辑器中 |
| `Ctrl+v` | 进入可视块模式（不粘贴） |
| 粘贴（`Cmd+v` 或右键菜单） | 无操作 |
| 输入法（IME）的组字与上屏 | 被丢弃 |
| `Backspace` / `Delete` | 无操作 |
| `Escape` | 保持原有含义：取消正在运行的查询，或离开编辑器 |
| 带 `Ctrl`、`Alt` 或 `Cmd` 的快捷键、方向键、鼠标 | 照常工作，包括撤销与重做 |

普通模式下光标总是停在某个字符上，不会越过行尾。离开插入模式时光标会像 Vim 一样后退一个字符。在空行上 `x` 不做任何事，因此不会合并行。

插入模式下，除 `Escape` 外，编辑器的行为与关闭 Vim 模式时完全相同，包括使用 `Ctrl+v` 粘贴。补全菜单或代码操作菜单打开时，`Escape` 关闭菜单并留在插入模式；否则返回普通模式。两种情况下焦点都留在编辑器中。存在多个光标或正在显示行内建议时，第一次 `Escape` 先清除它们，下一次才返回普通模式。

可视模式下，`d` / `x` 删除字符、整行或块选区；块删除针对各行实际分离的范围，合并为一个撤销步骤。`y` 将选区复制到系统剪贴板。选区为空时，这些命令返回普通模式，不编辑文本或更改剪贴板。只读编辑器中，可视 `d` / `x` 保留选区，不编辑或更改剪贴板；`y` 仍可用。`dd` 和 `cc` 仅限普通模式。可视块 `c` 在每一个达到块左列的行上删除块中的列，跳过更短的行，并在其中第一行进入插入模式。用 `Escape` 结束插入时，在那里输入的文本会插入到其他行的同一列。如果输入的文本包含换行、没有输入任何内容，或焦点先离开了编辑器，则不会复制。块的列按 Unicode 标量计数，与块选择相同。删除、输入的文本和复制内容合为一个撤销步骤。

**修改与撤销。** 普通模式下，`c` 支持按字符的 `h` / `l`、按整行的 `j` / `k`、单词移动 `w` / `W` / `e` / `E` / `b` / `B`、按整行的 `gg` / `G`，以及 `cc`。`cw` 修改到下一个 `w` 边界。操作符前与移动前的次数相乘（`2c3w` 覆盖六次 `w` 移动）；绝对目标行从 1 开始计数且限制在缓冲区内（`2c3G` 指向第 6 行），不带次数的 `cG` 指向末行。按行修改保留下一行之前的分隔符；带次数的 `cc` 包括目标行已有的 LF 或 CRLF 行尾符。修改通过原生编辑删除目标后进入插入模式输入替换文本。普通会话中，删除与替换合为一个撤销步骤，并恢复第一个光标。只读编辑器中不会修改文本，也不会进入插入模式。

字符和整行可视模式的 `c` 通过原生编辑修改包含末尾位置的选区，并进入插入模式输入替换内容。普通会话中一次撤销即可恢复原始文本和折叠后的锚点；用于执行查询的选中文本字节不变。只读编辑器中，`c` 保留选区且不进入插入模式。字符或整行选区为空时，`c` 不删除文本，直接进入插入模式。按行修改也处理 LF 或 CRLF 后的末尾空逻辑行。

**替换。** `r{字符}` 替换光标下的字符，光标留在该字符上。带次数时，`3rx` 用 `x` 替换本行接下来的三个字符；如果到行尾剩余的字符不足，则不做任何修改。它从不替换换行符，在空行上不执行操作。`r` 后接 `Enter` 会把这些字符替换为一个保留本行缩进的换行；`r` 后接 `Tab` 写入制表符。`Escape`、`Backspace`、`Delete`、方向键或离开编辑器会取消 `r` 而不做编辑；带 `Ctrl`、`Alt` 或 `Cmd` 的快捷键会先取消它，再照常执行。`r` 接受通过输入法（IME）组字得到的字符。替换是一个撤销步骤。

`R` 进入替换模式。每个输入的字符覆盖光标下的字符；在行尾时追加，而不会替换换行符。`Backspace` 按相反顺序恢复本次替换会话覆盖的字符，没有可恢复的字符时只向左移动。`Enter` 插入换行，`Tab` 缩进，与插入模式相同。`Escape` 返回普通模式并把光标后退一个字符。整个替换会话是一个撤销步骤。`R` 前的次数会被忽略。

每次执行 `x`、`dd` 或带移动的 `d` 都是一个撤销步骤，包括带次数的命令。一次普通插入模式会话中输入的内容是一个步骤，每次新会话开始新的步骤。一个撤销组最多容纳 1000 次修改，因此长会话可能需要多次撤销。`u` 撤销的步骤与 `Ctrl+z` / `Cmd+z` 相同。

**输入法限制。** 如果上次组字的迟到取消标记事件在下一次组字开始后到达，可能过早提交当前原生组字并拆分 Vim 撤销组。切换到只读或普通模式时，正在显示的待确认组字文本会按原样提交，而不会接受之后的候选词。替换模式下，不经按键到达的文本（例如输入法上屏）会被插入而不是覆盖，`Backspace` 也不会恢复它周围的字符。这不代表输入法完全安全；尚未进行实际界面验证。

**只读编辑器**（例程定义）允许移动、`yy` 和带移动的 `y`；
`x`、`r`、`R`、`dd`、`cc`、带移动的 `c` / `d`、可视模式的 `c` 和 `u` 不执行操作。删除操作也不会更改剪贴板。

**限制。**

- 只支持第一张表中的命令。`dd` 和 `yy` 作用于完整逻辑行，包括已有的行尾符。
  到达文件末尾时，次数止于最后一行；删除末行还会移除其前面的分隔符，
  复制时则不会补充原本不存在的换行符。对于由 LF 或 CRLF 形成的末尾空行，
  按行操作的 `y` 会复制已有的分隔符；空文件没有可复制的分隔符。带单词移动的 `d` / `y`
  支持 `w` / `W` / `e` / `E` / `b` / `B`：`w` / `W` 和 `b` / `B`
  不包含目标字符，`e` / `E` 包含目标字符。操作符结合 `h` / `l`
  按字符处理，结合 `j` / `k` 按逻辑行处理。不支持
  其他标记、文本对象、寄存器、宏、`.` 重复、`:` 命令或重做键。
  这不是完整的 Vim。
- 移动按 Unicode 码位逐个进行，与方向键相同，因此用单独的组合重音符号写成的字母需要按两次。
- 普通模式只拦截你的输入和粘贴。DBFlux 自身进行的编辑，例如加载文件或历史中的查询，仍会生效。

## 通知中心

标题栏最右侧的铃铛会打开通知中心，这是一个浮在工作区上方的弹出面板。它列出等待决定的 MCP 审批、你执行的操作所报告的错误、可用的 DBFlux 更新，以及已完成的导出、导入、迁移和转储分析任务。铃铛上的徽标显示未读数量，颜色取决于最紧急的未读项：错误为红色，审批为强调色，更新和已完成任务为中性色。没有未读项时，铃铛不显示徽标。

打开弹出面板不会把任何项标为已读。点击某一行会打开它的目标并将其标为已读：审批会在 MCP 审批标签页中打开该请求，错误会打开按其关联 ID 筛选的审计，更新会打开其发行说明，已完成任务会打开后台任务面板。**全部标为已读**会读完所有项，**清除已读**会移除已读项。列表只在本次会话中保留。更新显示在这里，不再显示在状态栏中。

| 按键     | 操作                                 |
|----------|--------------------------------------|
| `Escape` | 关闭弹出面板（点击面板外部效果相同） |
