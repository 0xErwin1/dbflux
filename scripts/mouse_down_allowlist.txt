# Left-button `on_mouse_down` handlers that need press semantics.
#
# Checked by `python3 scripts/lint.py mouse-down`. Activations (open, toggle,
# select, run) use `on_click`, which fires on release and gives the element an
# accessibility click action. A handler listed here must act on the press.
#
# Format: `path:function: reason`, one line per handler. `function` is the
# innermost `fn` around the handler, so a function with two press handlers is
# listed twice. Reasons:
#   propagation guard      - only stops the press from reaching an ancestor's press handler
#   focus guard            - prevents the default so the press does not move focus
#   outside-press dismiss  - a scrim or backdrop that closes its overlay on press
#   resize grip            - starts a resize drag
#   drag start             - starts a drag or move
#   selection start        - starts a cell, text, or range selection
#   focus on press         - moves keyboard focus on press, before a text input blurs
#   cursor sync            - moves a form's keyboard cursor to the pressed control before the control handles the press
#   edit commit            - commits an open inline edit before its editor blurs
#   unverified             - not yet proven safe to move to release
